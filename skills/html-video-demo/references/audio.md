# 旁白、字幕与转场

## 配音策略

优先沿用已确认的声音。新声音用同稿、原速、等响度的短片段比较：中文或目标语言的自然度、英文产品名和术语、句间衔接、最后一个字是否完整。不要把降低音量或拉慢播放当作模型已经更自然的证据。

内置默认是 Qwen3-TTS 1.7B CustomVoice 的 MLX 8-bit 版本与 Serena 预设。这是已验证组合，不是对所有视频的强制选择。固定音色、风格、语言和随机种子；生成边界越碎，重新定调越频繁。默认按有界文本预算聚合相邻场景，可以用显式 `groups` 表达更合理的语义分组。

中文约 20–45 秒的一组可作为试验起点，实际长度由音色和内容决定。遇到长文重复、失控或不结束时，缩小出问题的组，不能只提高 token 上限。不同模型、语言和音色应重新验证预算。脚本达到 token 上限会报错，不输出“成功成片”。

多个生成组先合成完整音轨，再统一响度，避免每章单独处理造成音量起伏。不要在已合成后大幅加速声音来凑既定时长；优先让画面跟随自然配音。

## 两种文字检查

**ASR** 从音频识别实际说了什么，用来找漏读、重复和明显术语错误。其结果可能把“源”写成“原”，所以需要看差异，不能只依据字符串相等自动验收。

**强制对齐** 已知文字，估计词或句子在音频中的位置。它会尝试把提供的文字对上音频，因此不能单独证明实际没有漏读。脚本要求对齐 token 覆盖原稿、时间不越界、字幕句区间非空且不重叠。

## 采样与切幕

1. 保留未经时长裁剪的原始生成音频。
2. 归一化整轨，按原稿得到词级时间。
3. 只在前一段最后一词结束、下一段第一词开始之间找低能量切点。
4. 验证各段拼回后与切分前采样完全相同。
5. 加入适当的开头留白和尾字后保持；技术讲解默认约一秒收尾。
6. 为操作录像保留完整播放时长，并让强调节点跟随语音时间。
7. 在最终 MP4 再检查切点，防止拼接、帧率和音轨合入阶段引入问题。

若两段之间没有安全停顿，脚本会停止该阶段。应检查对齐、重新分组或重做该段；不要把阈值不断放宽到可以切进元音里。呼吸声、背景音和配乐需要单独判断，内置切点验证针对没有背景音乐的讲解旁白。

## 检查结尾

文件结束时仍有明显语音能量，或最后一词被挤到极短区间，都是需要听取和排查的信号。能量阈值不是语音完整性的证明：很轻的辅音也有意义，ASR 也可能根据上下文补出缺失字。结合原始波形、解码长度、独立转写和试听来判断。

升级模型或运行库后，重新测试中英混读、长句和句尾；确认音色一致性后再导出整片。
